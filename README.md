# chausen.dev

This is the source code for my portfolio website, built with [Astro](https://astro.build/).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the `main` branch.

**Custom Domain:**
The site uses the custom domain `chausen.dev`. This is configured in `astro.config.mjs` and a `CNAME` file in the `public/` directory.

## Architecture

- **Framework:** Astro
- **Styling:** Tailwind CSS (via Vite plugin)
- **Content:** MDX
- **Hosting:** GitHub Pages
